# System Change Coordination Checklist

## Before
- Define purpose and scope
- Identify affected users, devices, and locations
- Document risk and dependencies
- Confirm backup / rollback path
- Schedule change window
- Communicate expected impact
- Confirm owner / approver

## During
- Record start time
- Follow implementation steps
- Capture deviations
- Validate connectivity and application health
- Escalate blockers early

## After
- Test expected functionality
- Confirm user / stakeholder acceptance
- Review event logs and service status
- Document results
- Close or update the change record
- Record lessons learned

## Example validation
- Endpoint boots normally
- IP configuration is correct
- DNS resolves expected names
- User can authenticate
- Required applications open
- Network drives / printers / services are reachable
- No new critical system errors appear
