# Desktop Support & Endpoint Operations Lab

A simulated desktop-support project designed to demonstrate end-user troubleshooting, endpoint inventory, incident handling, system-change coordination, network diagnostics, and support documentation in an enterprise / industrial environment.

> **Important:** All users, devices, tickets, and change records are simulated for portfolio use. No confidential company data is used.

## What this project includes
- PowerShell endpoint inventory and health-check script
- Simulated support-ticket dataset
- Desktop troubleshooting runbook
- Change-management checklist
- Simple support KPI analysis
- Multi-site / industrial support considerations

## Skills demonstrated
- Windows desktop support
- PowerShell
- TCP/IP, DHCP, DNS, ping and ipconfig diagnostics
- Software / workstation troubleshooting
- Incident triage and escalation
- Change planning and validation
- Documentation and knowledge-base creation
- Support KPI reporting
- Working with help desk and network operations

## Interview explanation
I built this lab to practice a structured desktop-support workflow. I created a PowerShell script that collects endpoint information and performs common support checks, generated a simulated ticket dataset, documented a repeatable troubleshooting process, and added a change-management checklist for workstation and application changes.

The project helped me connect my previous network-support experience with end-user support, system reliability, and coordinated technical changes.
